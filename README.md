# 話中話解碼器 Statement Decoder

把別人的一句建議、評論或勸告拆成可驗證事實、個人觀點與真正值得參考的訊號。

## 兩種使用入口

- **一般使用者**：使用公開網站貼上一句話，取得固定五步驟分析、瀏覽案例並匿名投稿，不需要理解 Prompt 或 Skill。
- **AI 使用者**：安裝本專案的 Claude Skill，或將跨平台 Prompt 加入 ChatGPT Custom GPT、Gemini Gem 與其他大型語言模型。

網站原始碼位於 `site/`，包含公開解碼介面、匿名投稿流程、案例分類與彙總數據儀表板。

## 概念說明

本專案的概念啟發自台灣講師姚詩豪的公開貼文：當一個人斷言某件事「沒有用」時，他表達的往往不只是外在世界的客觀結論，也可能包含自己的興趣、接觸程度、經驗與限制。若說話者具有資歷或權威，我們更容易忽略這層差異，把個人觀點直接當成事實。

我們建立這個工具，是希望在人受到一句話影響、開始焦慮或懷疑自己時，提供一個安全的停頓點：先查證事實、辨識觀點，觀察類似話語是否反覆出現，再決定哪些提醒值得採納。工具不把所有建議視為操控，也不替任何人做心理診斷。

> 姚詩豪 Facebook 原始公開貼文：待取得可核對的分享連結後補上；本專案只重述概念，不複製原文。

本專案為獨立開源發想與實作，與姚詩豪本人無合作、授權、代言或隸屬關係；專案內容、分析與相關責任均由本專案維護者承擔。

Statement Decoder 提供一套固定的五步驟框架：分離事實與觀點、檢核經驗、辨識可能的投射、對不相干的權威打折，最後保留真正可採納的訊號。它不是用來否定別人，而是幫助你更清楚地思考。

## 六類話術速覽

| 類型 | 代表案例 | 優先檢查 |
| --- | --- | --- |
| 否定勸退型 | 「學 AI 沒用啦！」 | 「沒用」的判準與證據 |
| 年齡／時間焦慮型 | 「你不年輕了，要趕快找工作了」 | 真實期限與個人焦慮 |
| 經驗權威型 | 「我吃過的鹽比你吃過的飯多，聽我的」 | 經驗是否與問題相關 |
| 恐嚇急迫型 | 「現在不做，以後就來不及了」 | 是否存在可驗證的截止條件 |
| 過來人合理化型 | 「我當年也是這樣熬過來的，你忍一忍就好」 | 過往經驗能否套用現在 |
| 比較型 | 「你看人家某某都已經買房了」 | 比較基準與條件差異 |

更多示範見 [examples/cases.md](examples/cases.md)。

## 安裝教學（Claude.ai）

1. 下載或複製本專案。
2. 將 `skill/statement-decoder/` 資料夾壓縮成 ZIP；ZIP 內應直接包含 `SKILL.md`。
3. 開啟 Claude.ai，進入「設定」中的 Skills 頁面。
4. 點選「+ Create skill」，上傳剛才建立的 ZIP。
5. 開啟這個 skill，並確認 Claude.ai 已開啟 code execution。
6. 回到對話，貼上別人對你說的話、建議或評論；符合情境時，skill 會自動觸發分析。

## 其他平台

沒有 Skills 功能也可以使用。請複製 [prompt.md](prompt.md) 的完整內容，貼入 ChatGPT Custom GPT 或 Gemini Gem 的指令欄；也可直接貼在一般大型語言模型對話的開頭，再提供要分析的話語。

## 使用範例

**輸入**

> 主管說：「你現在離職，履歷就毀了。」

**輸出**

1. **事實 vs 觀點分離**：離職時間與任職長度可驗證；「履歷就毀了」是強烈的主觀預測，需用產業資料或實際招募標準支持。
2. **說話者經驗檢核**：主管是否做過招募、是否了解你的目標職缺尚不清楚；可追問他看過哪些具體案例。
3. **投射偵測**：一種解讀是主管擔心人力流失，也可能真心擔心你的風險；目前不能確定動機。
4. **權威折扣**：主管了解現職，不代表同樣了解外部市場；其職位不能替代相關證據。
5. **可採納殘餘**：離職確實可能需要向未來雇主說明，值得先確認市場需求、準備說法與備用方案。

**一句話總結**：別把「履歷會毀掉」當定論，但要把轉職敘事與市場驗證當成離職前的必要功課。

## 免責聲明

本工具提供思考框架，不構成心理、職涯、法律、醫療或其他專業建議。面對高風險決策，請查證資料並諮詢合格專業人士。

## 隱私與數據

- 一般解碼輸入只用於當次分析，不寫入產品統計資料庫。
- 統計資料只記錄事件類型、話術分類、情境類型與時間，不建立個人心理檔案。
- 匿名投稿會保存原文與情境，以改善分類規則，以及用於未來去識別化的模型訓練與評測；投稿者必須先移除姓名、公司、地點及其他可識別資訊。
- 原始投稿不會公開、不會販售，也不會用於廣告。若未來希望改寫為公開案例，會另行取得投稿者同意。
- 數據儀表板顯示完成解碼數、投稿數、有幫助率、Skill 導流與分類分布等彙總指標。
